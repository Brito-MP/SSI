
1. Para listar as capabilities do sistema, usei:

capsh --print

2. O programa webserver.c aceita uma porta como argumento, cria um socket TCP e tenta fazer bind nessa porta.

Compilação:

gcc webserver.c -o webserver

Teste com porta não privilegiada:

./webserver 4050

Teste com porta privilegiada:

./webserver 80

3. Ao tentar usar a porta 80 com um utilizador normal, o resultado esperado é um erro de permissão no bind.
Isto acontece porque portas abaixo de 1024 são portas privilegiadas.

Uma forma de resolver sem executar o programa como root é dar ao executável a capability CAP_NET_BIND_SERVICE:

sudo setcap cap_net_bind_service=+ep ./webserver
getcap ./webserver
./webserver 80

Assim, o programa ganha apenas a permissão necessária para fazer bind a portas privilegiadas, em vez de receber todos os privilégios de root.
